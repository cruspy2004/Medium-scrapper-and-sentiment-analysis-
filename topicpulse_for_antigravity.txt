WHAT IS THIS PROJECT?
================================================================

TopicPulse is a web-based content intelligence tool. A user enters
a topic tag (e.g. "ai", "python", "llm") and the tool:

1. Scrapes Medium articles related to that tag via RSS
2. Scrapes Stack Overflow questions related to that tag via HTML
3. Runs AI sentiment analysis on article titles using Google Gemini
4. Ranks authors by influence (claps + responses)
5. Identifies content gaps on Stack Overflow (high views, few answers)
6. Displays everything on a dashboard with charts and CSV export

The goal is to go from class project to a live, deployed, resume-worthy
production tool hosted on Render.

--- PROBLEM STATEMENT ---

Content creators, developers, and researchers have no fast way to
understand what's trending in a technical niche, who the key voices
are, or what questions are going unanswered. They spend hours manually
reading articles and forums.

--- TARGET USERS ---

- Indie developer / content creator: wants to know trending topics
  to write about in a niche
- Student researcher: needs to map community sentiment and key voices
  for a study
- Founder: wants to track whether sentiment around their topic is
  positive or negative for timing content campaigns

"As a content creator, I want to enter a topic tag and see the top
authors writing about it so I know who to follow and what's being
covered."

"As a developer, I want to search Stack Overflow by tag and find
high-view questions with few answers, so I know where there are
content gaps I can fill."

"As a founder, I want to see whether sentiment around my topic is
trending positive or negative so I can time my content campaigns."

--- USER FLOW ---

Step 1: User visits TopicPulse homepage
Step 2: Chooses Medium or Stack Overflow
Step 3: Enters tag(s) and page count
Step 4: Clicks Scan
Step 5: Views results dashboard (articles, authors, sentiment, summary)

--- SYSTEM ARCHITECTURE ---

TopicPulse is a single Flask app with a 4-layer architecture.
(The old class project used multiple ports — this version collapses
everything into one unified app for clean production deployment.)

Layer 1 — Presentation Layer
  Technology: Jinja2 templates, Chart.js, Vanilla JS
  Role: Flask renders HTML server-side. Chart.js handles the sentiment
  donut chart and author bar chart on the client. No React — keeps the
  stack simple and deploy-friendly.

Layer 2 — Route Layer
  Technology: Flask Blueprints (routes/medium.py, routes/stackoverflow.py)
  Role: Route handlers are thin. They receive the request, call the
  appropriate service function, and pass results to the template.
  No business logic lives in route files.

Layer 3 — Analysis Layer
  Technology: analysis/sentiment.py, analysis/influence.py,
              analysis/opportunity.py
  Role: Gemini API calls for sentiment classification. Pandas
  aggregations for author influence scoring and SO opportunity scoring.
  TextBlob as fallback if Gemini is unavailable.

Layer 4 — Data Layer
  Technology: scrapers/medium.py, scrapers/stackoverflow.py,
              concurrent.futures
  Role: RSS/HTTP scraping with BeautifulSoup. Multi-tag batch runs use
  ThreadPoolExecutor for parallel fetching. Results are normalized into
  Pandas DataFrames before passing up to the analysis layer.

--- GEMINI INTEGRATION ---

Sentiment classification (batch call):
- Send up to 10 article titles per API call to minimize latency
- Prompt asks Gemini to return a JSON array with sentiment, confidence,
  and a max-10-word reason for each title
- If Gemini API fails for any reason, fall back to TextBlob

Code (analysis/sentiment.py):

  import google.generativeai as genai
  import json, os
  from textblob import TextBlob

  genai.configure(api_key=os.environ["GEMINI_API_KEY"])
  model = genai.GenerativeModel("gemini-1.5-flash")

  def classify_sentiment_batch(titles: list[str]) -> list[dict]:
      prompt = f"""
  Classify the sentiment of each article title below.
  Return a JSON array only — no markdown, no explanation.
  Each item: {{"sentiment": "POSITIVE"|"NEGATIVE"|"NEUTRAL",
               "confidence": 0.0-1.0, "reason": "max 10 words"}}
  Titles: {json.dumps(titles)}
  """
      try:
          response = model.generate_content(prompt)
          return json.loads(response.text)
      except Exception:
          return [_textblob_fallback(t) for t in titles]

  def _textblob_fallback(title: str) -> dict:
      polarity = TextBlob(title).sentiment.polarity
      sentiment = "POSITIVE" if polarity > 0 else \
                  "NEGATIVE" if polarity < 0 else "NEUTRAL"
      return {"sentiment": sentiment,
              "confidence": abs(polarity),
              "reason": "TextBlob fallback"}

Topic summary call:
- Called once per scan with up to 30 article titles
- Gemini returns a 2–3 sentence summary of what the community is
  currently discussing, problems being solved, and overall tone

  def generate_topic_summary(topic: str, titles: list[str]) -> str:
      prompt = f"""
  You are analyzing content about "{topic}".
  Here are recent article titles from Medium on this topic:
  {json.dumps(titles[:30])}
  In exactly 2-3 sentences, summarize what this community is currently
  discussing, what problems they are solving, and whether the overall
  tone is optimistic or concerned. Be specific and direct.
  """
      try:
          response = model.generate_content(prompt)
          return response.text.strip()
      except Exception:
          return "Summary unavailable."

--- SCRAPER SPECIFICATIONS ---

Medium Scraper (scrapers/medium.py):
- Fetches Medium RSS feed: https://medium.com/feed/tag/{tag}
- Parses with BeautifulSoup (xml mode)
- Extracts: author (dc:creator), title, URL
- Claps and responses are set to 0 (RSS doesn't include them)
- Multi-tag batch uses ThreadPoolExecutor (max 5 workers)
- Results deduplicated by URL in Pandas

  MEDIUM_RSS = "https://medium.com/feed/tag/{tag}"

  def scrape_tag(tag: str, pages: int = 1) -> list[dict]:
      url = MEDIUM_RSS.format(tag=tag.strip().lower())
      response = requests.get(url, timeout=10,
                              headers={"User-Agent": "Mozilla/5.0"})
      soup = BeautifulSoup(response.content, "xml")
      articles = []
      for item in soup.find_all("item"):
          articles.append({
              "author":    item.find("dc:creator").text,
              "title":     item.title.text,
              "url":       item.link.text,
              "claps":     0,
              "responses": 0,
              "tag":       tag,
              "sentiment": None,
              "confidence":None,
              "reason":    None
          })
      return articles

  def scrape_tags_batch(tags: list[str], pages: int = 1) -> pd.DataFrame:
      with ThreadPoolExecutor(max_workers=5) as executor:
          results = list(executor.map(lambda t: scrape_tag(t, pages), tags))
      flat = [a for tag_result in results for a in tag_result]
      return pd.DataFrame(flat).drop_duplicates(subset=["url"])

Stack Overflow Scraper (scrapers/stackoverflow.py):
- Scrapes HTML from: https://stackoverflow.com/questions/tagged/{tag}
- Parses question title, votes, answers, views
- Calculates opportunity_score = views / (answers + 1)

  SO_BASE = "https://stackoverflow.com/questions/tagged/{tag}?tab=votes&page={page}"

  def scrape_tag(tag: str, pages: int = 2) -> list[dict]:
      questions = []
      for page in range(1, pages + 1):
          url = SO_BASE.format(tag=tag, page=page)
          r = requests.get(url, timeout=10,
                           headers={"User-Agent": "Mozilla/5.0"})
          soup = BeautifulSoup(r.content, "html.parser")
          for q in soup.select(".s-post-summary"):
              title_el  = q.select_one(".s-post-summary--content-title a")
              stats     = q.select(".s-post-summary--stats-item-number")
              views_str = q.select_one("[title*='views']")
              votes   = int(stats[0].text.replace(",","")) if stats else 0
              answers = int(stats[1].text.replace(",","")) if len(stats)>1 else 0
              views   = int(views_str["title"].split()[0].replace(",","")) \
                        if views_str else 0
              questions.append({
                  "title":             title_el.text.strip() if title_el else "",
                  "url":               "https://stackoverflow.com" +
                                       title_el["href"] if title_el else "",
                  "votes":             votes,
                  "answers":           answers,
                  "views":             views,
                  "opportunity_score": round(views / (answers + 1), 1)
              })
      return questions

  influence_score = (total_claps × 2) + total_responses

  author_df = articles_df.groupby('author').agg(
