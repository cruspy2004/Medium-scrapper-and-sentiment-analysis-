WHAT IS THIS PROJECT? (READ THIS FIRST)
================================================================

TopicPulse v2 is a CONTENT GAP FINDER — this is a significant
upgrade from v1 (which was a general topic analysis dashboard).

The new core idea: a user types any topic (e.g. "vector databases"),
and the tool cross-references TWO signals to surface the 5 best
content opportunities:

  Signal 1 — Medium saturation:
    How much content already exists on this topic?
    What is the community sentiment — are writers positive or
    frustrated? High volume + positive = crowded. Low volume or
    negative sentiment = opportunity.

  Signal 2 — Stack Overflow demand:
    How many people are asking questions that aren't getting answered?
    Opportunity score = views / (answers + 1).
    A question with 50,000 views and 1 answer = screaming demand.

These two signals are combined into a single "Content Gap Score"
(0.0–1.0). The top 5 gaps are displayed. The user can click any gap
to get a full AI-generated content brief: suggested title, target
audience, key points to cover, top unanswered questions to address,
and a difficulty-to-rank score.

One-line pitch:
"Type a topic. Get the 5 things you should write about this week
— and a full brief for each one."


================================================================
KEY CHANGE FROM v1
================================================================

v1 was: scrape Medium + Stack Overflow → show sentiment dashboard
        + author ranking → export CSV.

v2 IS: scrape Medium + Stack Overflow → compute content gap scores
       → show ranked gap list → click any gap → Gemini generates
       a full content brief on the fly (no page reload).

The old author influence ranking and separate Medium/SO pages are
GONE. Everything is now a unified single-topic scan that outputs
ranked content opportunities.

--- THE CONTENT GAP SCORE FORMULA ---

gap_score = (so_opportunity_score × 0.6)
          + (sentiment_penalty × 0.3)
          + (volume_penalty × 0.1)

Where:
  so_opportunity_score = views / (answers + 1), normalized to 0–1
  sentiment_penalty    = 1.0 if NEGATIVE, 0.5 if NEUTRAL,
                         0.0 if POSITIVE
  volume_penalty       = 1 - (article_count / max_article_count)

Weights: Stack Overflow demand is the strongest signal (60%).
Existing sentiment on Medium is meaningful (30%).
Raw article volume is a minor tiebreaker (10%).
All components are normalized to 0–1 before weighting.

Difficulty score (shown on brief):
  difficulty = inverse of gap_score, mapped to a 1–5 scale.
  High gap = low difficulty to rank (bar is low, content is poor).
  Low gap = high difficulty (well covered, hard to compete).

Decision matrix (when to write):
  High SO opportunity + Negative/Neutral sentiment + Low volume
    → WRITE THIS (high demand, nobody's cracked it yet)
  High SO opportunity + Positive sentiment + Medium volume
    → WRITE THIS (demand is real, appetite for more)
  Medium SO opportunity + Negative sentiment + High volume
    → WRITE IF YOU HAVE A NEW ANGLE (crowded but disappointing)
  Low SO opportunity + Positive sentiment + High volume
    → SKIP (saturated, no gap)
  Low SO opportunity + Any sentiment + Low volume
    → SKIP (no demand)

--- SYSTEM ARCHITECTURE ---

Single Flask app with 4 layers.

KEY ARCHITECTURAL DECISION: Gap scoring and brief generation are
SEPARATE CONCERNS.
- Scoring happens server-side at scan time (POST /scan).
- Brief generation happens ON-DEMAND per click (POST /brief).
  This is a client-side fetch() call — no page reload.

Layer 1 — Presentation Layer
  Technology: Jinja2 templates, Chart.js, Vanilla JS fetch()
  Role: Flask renders the gap list at scan time. Brief drill-down
  uses fetch() to call /brief and injects the result into a modal
  panel. No React — keeps the stack simple.

Layer 2 — Route Layer
  Technology: Flask Blueprints (routes/scan.py, routes/brief.py)
  Role: Two blueprints.
    scan  — full pipeline: scrape, analyse, score, render.
    brief — single POST that receives gap context, returns
            Gemini-generated brief as JSON.

Layer 3 — Analysis Layer
  Technology: analysis/sentiment.py, analysis/gap_score.py,
              analysis/brief.py
  Role: Sentiment classification (Gemini batch + TextBlob fallback).
  Gap score computation (Pandas). Brief generation (Gemini,
  on-demand). All pure functions — no Flask imports.

Layer 4 — Data Layer
  Technology: scrapers/medium.py, scrapers/stackoverflow.py,
              concurrent.futures
  Role: Both scrapers run in parallel via ThreadPoolExecutor.
  Each returns a normalized list of dicts that gets converted to a
  Pandas DataFrame before passing to the analysis layer.

--- GAP SCORE IMPLEMENTATION (analysis/gap_score.py) ---

import pandas as pd

def compute_gap_scores(articles: list[dict], questions: list[dict]) -> list[dict]:
    art_df = pd.DataFrame(articles)
    q_df   = pd.DataFrame(questions)

    # Stack Overflow signal
    q_df["opportunity_score"] = q_df["views"] / (q_df["answers"] + 1)
    max_opp  = q_df["opportunity_score"].max() or 1
    so_signal = q_df["opportunity_score"].sum() / max_opp  # normalized 0–1

    # Medium signals — group articles by tag (subtopic)
    grouped = art_df.groupby("tag")
    gaps = []
    for tag, group in grouped:
        sentiment_counts = group["sentiment"].value_counts()
        n_pos = sentiment_counts.get("POSITIVE", 0)
        n_neg = sentiment_counts.get("NEGATIVE", 0)
        n_neu = sentiment_counts.get("NEUTRAL",  0)
        total = len(group)

        # Sentiment penalty: high negative = bigger gap
        sentiment_penalty = (n_neg * 1.0 + n_neu * 0.5) / total if total else 0.5
        gaps.append({
            "tag":              tag,
            "so_signal":        so_signal,
            "sentiment_penalty":sentiment_penalty,
            "volume_raw":       total,
            "article_count":    total,
            "sample_titles":    group["title"].head(5).tolist(),
            "n_pos": n_pos, "n_neg": n_neg, "n_neu": n_neu,
        })

    gaps_df = pd.DataFrame(gaps)

    # Normalize volume penalty
    max_vol = gaps_df["volume_raw"].max() or 1
    gaps_df["volume_penalty"] = 1 - (gaps_df["volume_raw"] / max_vol)

    # Composite gap score
    gaps_df["gap_score"] = (
        gaps_df["so_signal"]         * 0.6 +
        gaps_df["sentiment_penalty"] * 0.3 +
        gaps_df["volume_penalty"]    * 0.1
    ).round(3)

    # Difficulty: inverse of gap score, mapped to 1–5
    gaps_df["difficulty"] = (
        5 - (gaps_df["gap_score"] * 4)
    ).round().astype(int).clip(1, 5)

    return gaps_df.sort_values("gap_score", ascending=False).head(5).to_dict("records")

--- GEMINI INTEGRATION ---

Sentiment classification (analysis/sentiment.py):

  import google.generativeai as genai, json, os
  from textblob import TextBlob

  genai.configure(api_key=os.environ.get("GEMINI_API_KEY", ""))
  model = genai.GenerativeModel("gemini-2.0-flash")  # USE THIS MODEL

  def classify_batch(titles: list[str]) -> list[dict]:
      prompt = f"""Classify sentiment for each title. Return JSON array only.
  Each item: {{"sentiment":"POSITIVE"|"NEGATIVE"|"NEUTRAL",
               "confidence":0.0-1.0,"reason":"max 10 words"}}
  Titles: {json.dumps(titles)}"""
      try:
          r = model.generate_content(prompt)
          return json.loads(r.text.strip().strip("```json").strip("```"))
      except Exception:
          return [_textblob(t) for t in titles]

  def _textblob(title: str) -> dict:
      p = TextBlob(title).sentiment.polarity
      s = "POSITIVE" if p > 0 else "NEGATIVE" if p < 0 else "NEUTRAL"
      return {"sentiment": s, "confidence": round(abs(p), 2),
              "reason": "TextBlob fallback"}

  NOTE: Send up to 10 titles per batch call to minimize latency.

Content brief generation (analysis/brief.py):

  def generate_brief(gap: dict) -> dict:
      prompt = f"""
  You are a content strategist. Generate a content brief for the topic gap below.
  Return JSON only — no markdown, no preamble.

  Gap context:
  - Topic: {gap['topic']}
  - Subtopic: {gap['gap_title']}
  - Gap score: {gap['gap_score']} (higher = bigger opportunity)
  - Medium sentiment: {gap['n_pos']} positive, {gap['n_neg']} negative,
    {gap['n_neu']} neutral articles
  - Sample Medium titles: {json.dumps(gap['sample_titles'])}
  - Top Stack Overflow questions: {json.dumps(gap['top_questions'])}

  Return this exact JSON shape:
  {{
    "suggested_title": "compelling, specific article title",
    "why_now": "2 sentences on why this gap exists and why now",
    "target_audience": "specific description of who will read this",
    "key_points": ["point 1", "point 2", "point 3"],
    "questions_to_address": [
      {{"title": "SO question", "views": int, "answers": int, "url": "string"}}
    ],
    "difficulty": int,
    "difficulty_label": "short label explaining the score"
  }}
  """
      try:
          r = model.generate_content(prompt)
          text = r.text.strip().strip("```json").strip("```")
          return json.loads(text)
      except Exception as e:
          return {"error": str(e),
                  "suggested_title": "Brief generation failed — try again."}

--- SCRAPER SPECIFICATIONS ---

Parallel execution wrapper (routes/scan.py):

  from concurrent.futures import ThreadPoolExecutor
  from scrapers.medium import scrape_tags
  from scrapers.stackoverflow import scrape_tags as so_scrape_tags

  def run_parallel_scrape(topics: list[str], pages: int):
      with ThreadPoolExecutor(max_workers=2) as ex:
          medium_future = ex.submit(scrape_tags, topics, pages)
          so_future     = ex.submit(so_scrape_tags, topics, pages)
          articles  = medium_future.result()
          questions = so_future.result()
      return articles, questions

Medium scraper (scrapers/medium.py):
  NOTE: Medium RSS does NOT include clap counts. Fetching claps
  requires visiting each article page (~1s per article, risks
  rate limiting). For v1, claps default to 0. Clap enrichment is
  optional for v2.

  MEDIUM_RSS = "https://medium.com/feed/tag/{tag}"

  def scrape_tag(tag: str, pages: int = 1) -> list[dict]:
      url = MEDIUM_RSS.format(tag=tag.strip().lower())
      try:
          r = requests.get(url, timeout=10,
                           headers={"User-Agent": "Mozilla/5.0"})
          soup = BeautifulSoup(r.content, "xml")
          return [{
              "author":    item.find("dc:creator").text
                           if item.find("dc:creator") else "Unknown",
              "title":     item.title.text,
              "url":       item.link.text,
              "claps": 0, "responses": 0,
              "tag": tag, "sentiment": None,
              "confidence": None, "reason": None
          } for item in soup.find_all("item")]
      except Exception:
          return []

Stack Overflow scraper (scrapers/stackoverflow.py):
  URL pattern: https://stackoverflow.com/questions/tagged/{tag}?tab=votes&page={page}
  Parses: title, votes, answers, views per question
  Calculates: opportunity_score = views / (answers + 1)
